# Outputs

Everything the lesson scripts produce: one CSV per step
(`step1_loaded.csv` … `step4_deduped.csv`), the final
`clean_listings.csv`, `quarantine.csv`, the SQLite database
`clean_listings.db`, and the Excel scorecard
`Data_Quality_Scorecard.xlsx`. Delete this folder and re-run the five
lesson scripts to regenerate it from scratch.
